## Anexo E. Errores típicos en traducción y uso de términos

> **Referencia:** Basado en Anexo E del enunciado. **Estos errores son penalizados.**

| Término original | Traducción correcta | Traducción incorrecta | Explicación |
| :---- | :---- | :---- | :---- |
| Library | Biblioteca | Librería | *Library* = biblioteca; *bookstore* = librería |
| Requirement | Requisito | Requerimiento | *Requirement* = requisito; *request* = requerimiento/solicitud |
| Request | Solicitud / Petición / Requerimiento | Requisito | Consecuencia de traducir mal *requirement* |
| Application | Aplicación | Aplicativo | *Aplicativo* no existe en español (solo en portugués) |
| Elicit | Obtener | Elicitar | *Elicitar* no existe en español |
| Deploy / Deployment | Desplegar / Despliegue | Deployar / Despliegue (como verbo sustantivado mal) | Usar término original o traducción correcta |
| Test / Testing | Probar / Prueba / Pruebas | Testear / Testeo | Usar término original o traducción correcta |
| Commit | Confirmar / Hacer commit | Comitear / Commitear | No mutar términos ingleses |
| Methodology | Marco de trabajo / Enfoque / Método | Metodología | Scrum es un *framework*, no una *metodología* |
| Apartado | Sección / Capítulo / Cuadro / Tabla | Apartado | Usar término preciso según contexto |

**Regla general:** En comunicación oral/escrita, solo términos en idioma original **o** traducción correcta. No mutaciones (*deployar*, *testear*, *comitear*).
